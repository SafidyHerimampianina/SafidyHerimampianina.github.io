# Captures de projets

Déposez ici vos captures (WebP, ~1200×750, < 150 Ko), puis indiquez le chemin
dans `js/data.js`, champ `image` du projet :

```js
{ id: 'omapi', image: 'assets/img/projects/omapi.webp', /* … */ }
```

Sans `image`, une maquette CSS (dégradé + fenêtre de navigateur) est générée.
