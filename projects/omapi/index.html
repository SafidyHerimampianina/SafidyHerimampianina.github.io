OMAPI back-office

Industrial property management platform with a form engine and generic CRUD.

Context

The Malagasy Industrial Property Office handles trademark, patent and design filings and needed a unified back-office for its staff.

Problem

Many filing types with similar yet different structures: hand-building every screen would have produced an inconsistent UI and hard-to-maintain code.

Solution & architecture

  • Layered architecture: React client, Spring API
  • Generic server-side functions to share business logic
  • Configuration-driven generic entry, list, detail and edit screens
  • Unit and integration tests on critical modules

Stack

  • React
  • Java
  • Spring
  • HTML
  • CSS
  • MySQL

My role

Design, architecture and full stack development, from database to interface.

Outcome

A consistent interface across every module, and new features shipped quickly thanks to reusable generic code.
