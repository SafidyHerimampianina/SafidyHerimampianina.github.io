Ketrika.com e-commerce & ticketing

E-commerce site redesign and online ticketing with an interactive seating plan.

Context

A BICI project: Ketrika.com, an e-commerce site, needed an easier-to-use interface and an online ticket booking system.

Problem

Navigation that was hard to use, and a ticketing system that had to handle seat availability in real time.

Solution & architecture

  • Design overhaul: reworked ergonomics and navigation, optimised interface
  • Front-end and back-end development with Java, JEE and JSP
  • REST APIs delivering dynamic content between the interfaces and the back-end
  • Integrated ticketing with an interactive seating plan so users pick their own seats
  • Back-end logic optimised for real-time seat availability

Stack

  • Java
  • JEE
  • JSP
  • API REST
  • JavaScript
  • PostgreSQL
  • HTML/CSS
  • Bootstrap

My role

Project maintainer from 2024 to September 2026: front-end and back-end development, from the interface redesign to the REST APIs, plus maintenance and improvements.

Outcome

A smooth, engaging booking journey, better system performance and higher user satisfaction.
